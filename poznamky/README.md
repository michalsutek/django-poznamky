## Ako dostanem nové poznámky

Na začiatku hodiny v koreni repozitára `django/`:

```powershell
git pull
git pull --no-edit poznamky main
```

Na konci hodiny ich spolu so svojou prácou nahráš na GitHub (`git push`), takže doma ich budeš mať po obyčajnom `git pull`.

> **Poznámky neupravuj.** Pri ďalšom sťahovaní by vznikol konflikt.
> Vlastné poznámky si píš do súboru `poznamky/moje-poznamky.md`.
